실제 페이지를 열지 못한 것은 확장 추출기의 실패율 100%라는 뜻이 아닙니다. 반대로 핵심 단위 테스트 통과도 실제 추출 성공을 의미하지 않습니다. 사용자 제공 집계는 확보했지만 매물별 원시 JSON과 실제 예시 데이터는 아직 없습니다. samples/real-session.json은 최초의 미시작 템플릿이며 현재 실측 결과가 아닙니다. 합성 데이터는 테스트 코드에만 있습니다.

사진 누락은 지연 로딩 또는 DOM 구조 차이가 원인일 수 있으나 현재 집계만으로 확정할 수 없습니다. 사용자가 목록 하단까지 직접 스크롤한 후 다시 추출하여 비교하고, 원시 JSON에서 warnings와 대표사진 누락 매물을 확인해야 합니다. 상세 매물은 직접 열어 별도 추출해야 합니다.

## 정책 검토

- [robots.txt](https://www.daangn.com/robots.txt): 본문 직접 조회 실패. 웹 도구가 홈페이지에 OAI-SearchBot robots 차단을 보고했습니다. 이것을 모든 사용자 에이전트와 수동 확장에 동일하게 적용된다는 결론으로 확대하지 않습니다. 경로별 Allow/Disallow 원문은 확인하지 못했습니다.
- [당근 홈페이지](https://www.daangn.com/kr/), [약관 후보 경로](https://www.daangn.com/kr/terms/): 도구 조회 실패. 후보 경로가 최신 공식 이용약관이라는 점도 미확인입니다. 실제 페이지 하단의 이용약관 링크를 사용자가 열어 자동화·수집·저작권 관련 조항과 시행일을 확인해야 합니다.
- [공식 개인정보 처리방침](https://privacy-policy.daangn.com/): 검색으로 확인됐으나 서비스 이용약관의 수집 허가를 대체하지 않습니다.
- 공개 화면을 사람이 볼 수 있는 것과 자동 수집·재배포·AI 전송이 허용되는 것은 별개입니다. **정책 적합성 확인 완료로 판단하지 않습니다.** 법적 적합성을 보증하는 보고서가 아닙니다.
- 따라서 24시간 무인 감시는 구현/활성화하지 않았습니다. timers에 의한 탐색, 탭 자동 생성, IP 회전, CAPTCHA 우회, 로그인 자동화, 비공개 API 호출/역공학은 없습니다.

## 성공률 산정 계획

고유 매물 20~30개를 사전에 고정하고 목록과 상세를 각각 대조합니다. 제목/가격/지역/URL/대표사진이 모두 존재하는 비율은 **구조적 완전율**입니다. 값의 정답 여부는 사람이 확인해야 합니다. 본문 정답률=본문이 원문과 일치한 매물/선정한 전체 상세 매물, 대표사진 정답률=해당 매물의 대표사진 확인/전체 매물, 전체 사진 확보율=갤러리 전체 사진과 대조 성공/전체 상세 매물입니다. 실제 사진이 한 장뿐인 매물은 다중 사진 필드 존재율과 구분합니다. 접근 실패를 제외한 조건부 비율을 추가로 계산할 경우 분모를 반드시 함께 표기합니다.

현재 자동 metrics는 관측 단위 필드 존재율이며 page_errors와 unique_listings를 별도 출력합니다. 재캡처가 많으면 관측율이 편향되므로 최종 실측 보고서는 CSV의 고유 매물 기준으로 작성해야 합니다.

## 알려진 기술 한계와 다음 단계

1. 실제 DOM을 아직 확인하지 않아 semantic selector 및 지역/가격 후보 선택이 다른 내용을 선택할 가능성이 있습니다. 추출기에 warnings를 남기며 원문 대조가 필수입니다.
2. main fallback은 관련 상품 사진을 포함할 가능성이 있어 전체 사진 성공으로 인정하지 않습니다. 실제 DOM 확인 후 갤러리 영역을 좁히는 것이 최우선입니다.
3. 동적 로딩·가상 목록·이미지 lazy loading은 수동 표시 범위만 읽습니다. 캡처 개수는 전체 검색 결과 개수가 아닙니다. src/currentSrc가 있어도 이미지 로딩 성공이나 영구 URL은 보장하지 않습니다.
4. 다음 작업은 사용자 Chrome 설치 → 20~30개 실측 JSON/대조표 확보 → 실제 DOM 기반 selector 수정 → 동일 샘플 재검증입니다.
5. 그 후 공식 약관/robots 원문과 운영 허용 범위를 확인하고, 필요하면 당근에 용도/빈도/보관 방식 승인을 문의합니다. 승인 전 무인 Playwright 운영으로 확대하지 않습니다.
6. V2 DB/앱 코드는 변경하지 않았습니다. PoC는 별도 폴더이며 운영 배포 대상에서도 제외했습니다.
