# V2.1 당근 수동 추출 PoC

기존 V2 장부와 DB에 연결하지 않는 독립 실험입니다. Vercel에도 배포하지 않습니다. 구현 완료와 실제 사이트 검증 완료는 서로 다릅니다. 현재 상태는 [검증 보고서](REPORT.md)를 확인하세요.

## Chrome 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. 이 폴더 아래 `extension` 폴더를 선택합니다. manifest.json이 있는 폴더입니다.
4. 확장 아이콘을 고정합니다. 수정된 소스를 사용할 때는 확장 관리 화면에서 새로고침합니다.

설치는 사용자가 직접 수행합니다. 권한은 activeTab(클릭한 탭), scripting(DOM 읽기 코드), storage(로컬 검증 기록)뿐입니다. 상시 사이트 권한, 쿠키, 웹 요청 감청, 자동 실행 서비스 워커가 없습니다.

## 실행과 실제 20~30개 검증

1. 사용자가 제공한 [서현동 컴퓨터 검색](https://www.daangn.com/kr/search/buy-sell/?in=%EC%84%9C%ED%98%84%EB%8F%99-4502&q=%EC%BB%B4%ED%93%A8%ED%84%B0)을 직접 엽니다. 페이지 로딩 후 확장 아이콘 → **현재 목록 추출**.
2. 최대 30개 중 페이지에 로드되어 표시 상태인 링크만 읽습니다. 뷰포트 밖에 있어도 CSS로 숨겨지지 않은 카드가 포함될 수 있습니다. 더 필요한 경우 사용자가 직접 스크롤하고 다시 클릭합니다. 자동 스크롤은 없습니다.
3. 동일 URL 재캡처는 로컬 records에서 병합됩니다. attempts에는 개별 시도를 보존합니다. 고유 매물 20~30개를 선정하고 제목·가격·지역·URL·사진을 원문과 대조합니다.
4. 선정한 매물을 **하나씩 직접 열고** 상세 추출을 누릅니다. 사진 슬라이더도 사용자가 직접 넘긴 뒤 다시 추출할 수 있습니다. 같은 매물의 사진 URL은 병합하지만 그것만으로 전체 사진을 확보했다고 판정하지 않습니다.
5. 삭제/로그인/차단/누락도 결과에 기록합니다. 성공한 매물만 골라 분모를 줄이지 마세요. 상세 접근 실패도 별도로 세어야 합니다.
6. **결과 JSON 저장**으로 내보냅니다. `samples/manual-audit.csv`에 원문 대조 결과를 기록합니다. 빈칸은 실패가 아니라 미검증입니다. 추천 매물 이미지가 섞였는지도 검사하세요.
7. `node summarize.cjs 결과.json`으로 구조적 추출률을 재계산합니다. 실제 정답률은 수동 대조 CSV에서 따로 계산합니다.

사진은 **URL만 저장**하며 사진 파일 다운로드·보관은 하지 않습니다. 로컬 JSON에 공개 글의 연락처 등 개인정보가 포함될 수 있으므로 외부 공유 전 검토하세요. 원문 전체나 사진을 재배포할 권리를 얻었다는 의미는 아닙니다.

## 데이터 계약과 후속 연결

- schema_version=1.0, source=daangn, id/source_id/canonical_url, title, price={amount,currency,raw,kind}, region, description, representative_image, images[], captured_at, provenance, warnings.
- null은 누락/미확정이며 0원은 나눔입니다. 금액은 정수 원입니다.
- canonical URL의 쿼리와 fragment를 제거합니다. 구형 articles 숫자 ID와 숫자 접미사 URL은 같은 숫자 ID로 묶고, 나머지는 slug 전체를 씁니다. 실제 신구 URL 대응은 미검증입니다. 같은 상품을 **새 글로 재등록**하면 ID가 달라지므로 자동 중복 제거할 수 없습니다. 제목/사진 유사도는 후보 표시만 하고 사람의 확인 없이 합치지 않는 것이 후속 원칙입니다.
- records는 누적 최신 상태, attempts는 원시 관측입니다. 상세가 실패해도 이전 관측의 값은 지우지 않습니다. 따라서 성공률은 records가 아닌 attempts를 기준으로 집계합니다.
- Python Playwright: 동일 계약을 출력하는 별도 어댑터만 제안합니다. 정책 확인 전 실행기·스케줄러를 구현하지 않습니다.
- AI 분석: JSON을 읽는 별도 소비자, 출처·불확실성·모델 버전 기록, 원문을 AI 지시로 실행하지 않음. 지금은 호출하지 않습니다.
- V2 가격 DB: 현재 DB를 변경하지 않음. 향후 별도 관측 테이블 + RLS + 승인된 추가 migration 후 명시적 가져오기로 연결합니다.
- Telegram: 별도 알림 큐/중복키/사용자 승인된 전송 대상이 필요합니다. 현재 전송 기능과 토큰은 없습니다.

## 로컬 테스트

Node.js에서 `node --test tests/core.test.cjs`로 의존성 없이 핵심 테스트를 실행합니다. DOM fixture 테스트는 이 폴더에서 `pnpm install --ignore-scripts` 후 `pnpm test`로 실행합니다. 실제 사이트 성공률과 합성 fixture 성공률을 혼동하지 마세요.

확장이 멈추거나 빈 결과를 주면 페이지를 다시 살펴보세요. CAPTCHA/접근 제한/로그인 요구를 우회하거나 비공개 API로 대체하지 않습니다. 서버 응답의 숨겨진 JSON, 쿠키, 토큰도 읽지 않습니다.
